## Steps
1. **File list** (`components.tsx`, `app.css`):
   - the pane is a `grid` with a name; the header is a `row` of `columnheader`s with `aria-sort`; each file is a `row` of `gridcell`s with `aria-selected`;
   - focus stays on the pane, which names the focused row with `aria-activedescendant`, only while that row is in the DOM;
   - the windowed list says its size (`aria-rowcount`) and each row its place (`aria-rowindex`); the card modes render every row and need neither;
   - column headers take focus: Up from the first row (a new press, not a held key) reaches them, Left/Right/Home/End move, Enter or Space sorts, Down goes back;
   - a polite message when another folder is listed (its name and how many items);
   - a row's selection flag stays a prop of that row only, so one change re-renders two rows.
2. **Tabs** (`components.tsx`, `app.css`): each tab bar is a `tablist`; a tab's label is the `tab` (`aria-selected`, roving `tabIndex`, Left/Right/Home/End), and its close control is a real button beside it. `data-tab-index`, `data-tab-bar`, `.label` and `.tab-btn` keep their places for `tabDrag.ts` and the e2e suite.
3. **Controls that aren't buttons:** the Inspector's edit/apply/cancel links, its quick-action chips and the checksum copy; the breadcrumb's segments and tag chip; the terminal head's two controls; the status bar's terminal switch; the sidebar's tree menu rows. The maximize button says Restore when the window is maximized.
4. **Keys on a focused control** (`keymap.ts`, `App.tsx`): Enter and Space on a button, tab or link are that control's, so they no longer also open the selection or Quick Look.
5. **Dialogs** (`dialogs/DialogPanel.tsx`, every overlay dialog): one wrapper gives `role="dialog"`, `aria-modal`, a name, focus into the dialog, Tab kept inside the top dialog, and focus back on close. Toasts go into a polite live region that's always in the page. The palette is a combobox over a listbox.
6. **Contrast** (`themes.css`, `themes.ts`, `themes.test.ts`, `app.css`): muted text (`--fg-3`) and secondary text (`--fg-2`) reach 4.5:1 on the file list, panels and hover in all 39 themes, with the original eight held to every check; the focus ring's color is checked on the surfaces it's drawn on; a selected row's muted cells use the row's own text color. Reduced motion and forced colors: cover what this task adds.
7. **Preferences:** the filter says when nothing matches (a status), and the dialog uses the shared wrapper.
8. **Ctrl+\\ on AltGr layouts** (`keymap.ts`): the binding also takes the physical backslash key with Ctrl.
9. **Tests and docs:** happy-dom tests for roles, names and key paths (`FilePane.a11y.dom.test.tsx`, tab strip, dialogs, keymap, themes); a 10,000-row render check that a selection change re-renders two rows; an AT-SPI tree check under Xvfb if the debug binary can run; hand checks for NVDA, Narrator and Orca in `docs/testing/`; `docs/ARCHITECTURE.md`; decisions in `docs/decisions/2026-11-23-a11y-*.md`.
